Tema 1

Representación Matricial de Sistemas de Ecuaciones

📌¿Qué es la representación matricial?

Un sistema de ecuaciones lineales puede expresarse de manera compacta como el producto de tres matrices:

Forma matricial: A · X = B
  • A: matriz de coeficientes de orden m×n
  • X: matriz columna de incógnitas de orden n×1
  • B: matriz columna de términos independientes de orden m×1

Donde m es el número de ecuaciones y n el número de incógnitas.

🔑¿Cómo construir la representación matricial?

1
Identificar los coeficientes de cada incógnita en cada ecuación. Si una incógnita no aparece, su coeficiente es 0.
2
Construir A: cada fila es una ecuación, cada columna es una incógnita.
3
Construir X: columna vertical con las incógnitas (x, y, z, …).
4
Construir B: columna vertical con los términos independientes (lado derecho de cada ecuación).

↔️El camino inverso: de matriz a sistema

También podemos reconstruir el sistema desde su forma matricial. Cada fila de A multiplica a X para dar la ecuación correspondiente en B.

Regla: fila i de A × columna X = elemento i de B
Si la fila es [a, b, c] y X = [x₁, x₂, x₃], la ecuación es: ax₁ + bx₂ + cx₃ = bᵢ

Tema 2

Método de Gauss — Eliminación Gaussiana

💡Idea general del método

El método de Gauss consiste en transformar un sistema en otro equivalente de resolución más sencilla: la forma escalonada (triangular superior).

Sistema original → (operaciones elementales) → Sistema escalonado
Ambos sistemas tienen el mismo conjunto solución.

⚙️Las 3 operaciones elementales de fila

#OperaciónNotación
1Multiplicar toda una fila por un número real no nuloFᵢ → k·Fᵢ (k ≠ 0)
2Sumar a una fila un múltiplo de otra filaFᵢ → Fᵢ + k·Fⱼ
3Intercambiar dos filasFᵢ ↔ Fⱼ
⚠️ Importante: Cada operación produce un sistema equivalente (misma solución). Nunca se pierde ni se gana información.

📋Procedimiento paso a paso

1
Escribir la matriz ampliada A* = (A | B) juntando la matriz de coeficientes y el vector de términos independientes.
2
Aplicar operaciones elementales de fila para hacer cero todos los elementos debajo de la diagonal principal (triangular superior).
3
Obtener la forma escalonada: la última fila tiene la variable más "simple", y se resuelve hacia arriba (sustitución regresiva).
4
Aplicar Rouché-Frobenius para clasificar el sistema según su tipo de solución.

📐La matriz ampliada A*

Para el sistema AX = B, la matriz ampliada se forma colocando B como última columna de A, separada por una barra vertical:

A* = (A | B)
Cada fila de A* contiene los coeficientes de las incógnitas Y el término independiente de esa ecuación.

Tema 3

Teorema de Rouché-Frobenius y Tipos de Sistemas

📏El Rango de una matriz

El rango de una matriz es el número de filas no nulas que quedan después de aplicar el método de Gauss (escalonamiento).

Rango = cantidad de filas con al menos un elemento distinto de cero en la forma escalonada.

⚖️Teorema de Rouché-Frobenius

Sea A·X = B un sistema de m ecuaciones con n incógnitas. Luego del escalonamiento comparamos:

  • r(A) = rango de la matriz de coeficientes
  • r(A*) = rango de la matriz ampliada
  • n = número de incógnitas
CondiciónTipo de sistemaSoluciones
r(A) ≠ r(A*) SI — Incompatible Sin solución
r(A) = r(A*) = n SCD — Compatible Determinado Solución única
r(A) = r(A*) < n SCI — Compatible Indeterminado Infinitas soluciones

🌳Árbol de decisión

Sistema m×n │ ├─ ¿r(A) = r(A*)? │ │ │ ├── NO ──→ SI (sin solución) │ │ │ └── SÍ │ │ │ ├── ¿r(A) = n? │ │ ├── SÍ ──→ SCD (solución única) │ │ └── NO ──→ SCI (infinitas soluciones)

🔢Sistemas m×n con m < n

Cuando hay más incógnitas que ecuaciones (m < n):
El sistema nunca puede ser SCD. Solo puede ser SI o SCI.

Esto se debe a que siempre r(A) ≤ m < n, por lo que la condición r(A) = n jamás se cumple.

Tema 4

Discusión del Tipo de Solución y Sistemas con Parámetros

🎯Discusión del tipo de solución

Cuando un sistema tiene parámetros (letras como m, k, a...) en sus coeficientes o términos independientes, el tipo de solución depende del valor del parámetro. El objetivo es determinar para qué valores el sistema es SCD, SCI o SI.

📋Estrategia para sistemas con parámetros

1
Aplicar el método de Gauss normalmente hasta obtener la forma escalonada.
2
Identificar la fila crítica: la fila donde aparece el parámetro en la posición determinante.
3
Analizar los casos:
  • Si el coeficiente de esa fila = 0 y el término ind. ≠ 0 → SI
  • Si el coeficiente de esa fila = 0 y el término ind. = 0 → SCI
  • Si el coeficiente de esa fila ≠ 0 → SCD

📌El conjunto solución en SCI

Cuando hay infinitas soluciones, se parametriza con variables libres:

Variables libres: las incógnitas que no tienen pivote en la forma escalonada. Se les asigna el parámetro t (o s, r, …) ∈ ℝ.

Variables dependientes: se expresan en función de los parámetros libres.

El conjunto solución se escribe como: S = {(f(t), g(t), t) : t ∈ ℝ}

🏭Problema de aplicación real

Problema: Una empresa fabrica 3 modelos usando insumos A, B, C:
M1: 3A + 2B + 5C | M2: 2A + 3B + 5C | M3: 5A + 2B + 5C
Disponible: A=100, B=67, C=150

Sistema:
3x + 2y + 5z = 100 (insumo A)
2x + 3y + 2z = 67 (insumo B)
5x + 5y + 5z = 150 (insumo C)

Solución única: x=14.5, y=7, z=8.5 → SCD
